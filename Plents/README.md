# Plants Landing — iPhone адаптив

## Описание

Этот файл содержит информацию об адаптации проекта **Plants Landing** под мобильные устройства iPhone.

## Поддерживаемые устройства

Адаптив рассчитан на следующие размеры экранов:

- iPhone SE
- iPhone 11 / 12 / 13 / 14
- iPhone 15 / 16
- iPhone Pro и Pro Max

## Основные изменения

### Navigation

- Навигация переносится на несколько строк.
- Расстояние между пунктами меню уменьшается.
- Кнопка Login становится компактнее.
- Элементы выравниваются по центру.

### Main section

- Главный блок становится вертикальным.
- Текст располагается над изображением.
- Размер заголовка уменьшается.
- Изображение подстраивается под ширину экрана.

### Flower cards

- Карточки перестраиваются в несколько рядов.
- На маленьких экранах карточки располагаются друг под другом.
- Текст выравнивается по центру.

### Cactus section

- Блоки располагаются вертикально.
- Изображения уменьшаются.
- Текст становится удобным для чтения на небольшом экране.

### Blog

- Blog-карточки перестраиваются в один столбец.
- Размер заголовков уменьшается.
- Между карточками добавляется расстояние.

### Footer

- Элементы Footer располагаются вертикально.
- Уменьшаются отступы.
- Текст центрируется.

## Breakpoints

Основной мобильный breakpoint:

```css
@media (max-width: 768px) {
    /* mobile styles */
}
```

Для маленьких экранов:

```css
@media (max-width: 480px) {
    /* small mobile styles */
}
```

## Анимации

В проекте используются простые CSS-анимации:

- плавное появление элементов;
- появление главного текста слева;
- появление главного изображения справа;
- увеличение изображений при наведении;
- плавное поднятие карточек;
- анимация кнопок.

## Цель

Адаптивная версия должна:

1. Корректно отображаться на iPhone.
2. Не создавать горизонтальный скролл.
3. Сохранять структуру оригинального дизайна.
4. Быть удобной для использования пальцами.
5. Сохранять плавные CSS-анимации.
